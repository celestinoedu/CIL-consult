# Cogna — Brand Assets

This folder holds the brand assets for Cogna.

## Files

| File | Use | Background |
|------|-----|------------|
| `cogna-logo-dark.svg` | Dark UI / dark backgrounds | `#111827` (Graphite) |
| `cogna-logo-light.svg` | Light UI / white backgrounds | `#FFFFFF` |

## Brand Colors

| Token | Hex | Role |
|-------|-----|------|
| Deep Teal | `#0F766E` | Primary |
| Graphite | `#111827` | Secondary / dark surface |
| Soft Neon Green | `#34D399` | Accent / gradient highlight |

The accent gradient runs from **Soft Neon Green → Deep Teal** and is applied to the `n` letterform of the wordmark.

## Typography

The wordmark uses a modern rounded sans-serif. Recommended stack:

1. Inter
2. Geist
3. Satoshi
